# FL_REPEAT

В этой папке лежат код обучения и предсказания, две обученные CNN, нормировщик и настройки обработки. [Финальная презентация](../presentation.pdf) описывает архитектуру и эксперименты.

| Файлы | Назначение |
| --- | --- |
| [`demo.py`](demo.py) | Проверка запуска на двух сгенерированных WAV |
| [`predict.py`](predict.py) | Предсказание на WAV/FLAC с готовыми или заново обученными весами |
| [`train.py`](train.py) | Обучение обеих сетей с нуля |
| [`src/`](src/) | Обработка сигнала, архитектура и обучающий цикл |
| [`models/`](models/) | Два комплекта весов для seed 639320754 и 639320755, статистики нормировки и параметры |
| [`config/`](config/), [`recipes/`](recipes/) | Настройки предобработки и финальный рецепт |
| [`research/`](research/) | Проверенные гипотезы и сравнения на локальных разбиениях |

Установите зависимости в отдельное окружение Python 3.12, как в [быстром старте](../README.md#проверить-запуск-без-датасета). Команды ниже выполняются из папки `work/`.

## Запуск на своих аудио

```bash
python predict.py --input /path/to/audio --output results/scores.npz --device cpu
```

Чтобы сохранить порядок из шаблона конкурса, передайте `--sample /path/to/sample_submission.csv`. Столбец `idx` содержит имена аудиофайлов с расширениями. Результат записывается в CSV и NPZ с полями `idx` и `score`. Рядом сохраняется JSON с параметрами запуска. Оценки предназначены для ранжирования, вероятности не калибровались.

## Обучение

Используйте обучающий набор соревнования. Код ожидает каталог с `targets.txt` и `flac/`. В каждой строке разметки второе поле — идентификатор FLAC без расширения, последнее — класс `bonafide` или `spoof`. Учебные FLAC должны быть моно, 16 кГц.

```bash
python train.py --train /path/to/train --device auto
python predict.py --models models/retrained/FL_REPEAT \
  --input /path/to/test_audio --output results/retrained.npz --device auto
```

При `--device auto` код пробует CUDA, затем MPS и CPU. При первом обучении строятся кэши в `data/cache/`. Для полного набора закладывайте около 90 ГБ свободного места вместе с окружением. Для другого набора используйте отдельный клон или перенесите локальный каталог `data/` и задайте новый `--out`.

По умолчанию каждая сеть проходит четыре эпохи с 3 000 выборками каждого класса за эпоху. Для короткой технической проверки возьмите маленький размеченный набор с обоими классами и запустите `python train.py --train /path/to/small_train --out models/retrained/smoke --draws-per-class 8 --workers 2 --device cpu`. Качество по такому запуску не оценивается.

Опубликованный пакет содержит код, веса и результаты исследований. Оригинальные аудио и файлы конкурсных ответов хранятся отдельно.
