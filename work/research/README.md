# Что проверяли

В таблице собраны ключевые эксперименты из командного журнала. Public — отображаемый конкурсный балл ROC-AUC × 100. Для сравнения изменений использовали согласованный контроль, когда он был доступен.

| Гипотеза | Что показал эксперимент |
| --- | --- |
| Восстанавливать пропуски и классифицировать по ошибкам | Модель на признаках ошибок получила 92,14 на Public. |
| Искать перепады между соседними полосами спектра | Канал спектральных разностей дал 99,22 против 97,24 у своего контроля. |
| Учить границы информативных фрагментов | 98,59 на Public. На трудном локальном разбиении метод уступил фиксированным границам. |
| Переоценивать подозрительные секунды второй сетью | 98,00 против 98,71 у контроля с равномерными участками. |
| Использовать фазу только там, где сигнал сильнее | Взвешенная фазовая ветка дала 95,76 против 90,86 у исходной фазовой ветки. |
| Убирать из представления информацию о дикторе обращением градиента | 99,31 против 99,48 у контроля. |
| Сохранить полную временную сетку вместо сжатия до 96 интервалов | Полная сетка вошла в итоговую архитектуру. Длину входа и размер батча проверяли отдельно. |
| Совместить короткие локальные аугментации FLAT и LOCAL | Повтор обучения этой комбинации с новыми seed получил 100,00 против прежних 99,74. Сравнение показывает чувствительность к seed. |

Идеи восстановления, спектральных разностей и повторной проверки секунд предложил Кирилл Тымчишин. Обучаемые границы фрагментов — идея Кирилла и Сергея Щеглова. Взвешивание фазы и обращение градиента проверяли по предложениям Codex. [Слайды 5 и 18–20](../../presentation.pdf) описывают часть этих экспериментов подробнее.

## Почему выбрали FL_REPEAT

| Рецепт | Public × 100 | Средний локальный ROC-AUC | Минимальный локальный ROC-AUC |
| --- | ---: | ---: | ---: |
| GAIN + FLAT | 99,88 | **0,962024** | **0,930554** |
| GAIN + LOCAL | 99,99 | 0,901359 | 0,791897 |
| FL_REPEAT | **100,00** | 0,905945 | 0,726018 |
| GAIN + FLAT + LOCAL | 99,91 | 0,943919 | 0,901077 |

В финале использовали лидера по Public. На трёх локальных разбиениях с исключёнными дикторами и генератором лучшим по среднему и минимуму оказался GAIN + FLAT. Самое слабое разбиение FL_REPEAT — G5/A05. Протокол эксперимента и ROC-AUC по каждому разбиению сохранены рядом.
